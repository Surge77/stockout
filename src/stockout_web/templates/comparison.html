Classification — predicting demand class

  {{ table(classification_rows, 'accuracy', 'Accuracy') }}
  

    The floor is {{ floor }} — what a model gets simply by always
    guessing whichever label is commonest, without looking at the day at all. Because each

    as common as each other, so anything at or below the floor has learnt nothing.
